▶ How to read this field — five findings
  • The field is split at the extraction/storage seam, and almost nothing crosses it. Every project with a credible claim model has no extractor; every project with a credible extractor has no store. The one system that genuinely spans both is INDRA — and it pays for it with a statement vocabulary hardcoded to molecular biology.
  • Passage-level provenance is much rarer than the band advertises. Only three mechanisms actually deliver it: GROBID's @coords, the W3C Web Annotation TextQuoteSelector, and LangExtract's char_interval. Everything else degrades on inspection.
  • Contradiction handling is four distinct mechanisms that get conflated. Detection, repudiation/supersession, evidence-strength modelling, and curatorial adjudication. No open system has all four. Detection without repudiation produces a list nobody acts on; repudiation without evidence strength is a vote.
  • The quantitative unit is absent from the entire open field. All 119 candidates store propositions — “X increases Y”. None types a magnitude: treatment versus control, n, effect size, dispersion, units, site-year. For agronomy that is the decision-grade unit.
  • Activity signals mislead in both directions, and single-maintainer governance is the mode. Star counts measure launch attention accumulated over years, not deployment. Several of the most-cited projects here are one person, and several dead ones are dead for reasons that are themselves findings.

Method. Sources were trusted in this order: primary repository contents; project documentation; GitHub API metadata for maturity and governance only, never adoption; published papers for design description only; vendor marketing to locate candidates, discarded at assessment. Licences, activity and capabilities are as verified in the August 2026 sweep.

Repository activity — last push, primary language, archive flag — was read from the GitHub API on 16 August 2026 for the 133 rows that name a GitHub repository, and drives the freshness dot and the maintained/stalled split. It measures the repository, not the project: a push includes documentation and bot commits, and for datasets, ontologies and specifications a quiet repository is not the same as an unmaintained resource. The survey's own Activity assessment is kept beside it on every card rather than replaced by it. Three organisation-level URLs are reported from their newest repository, and one URL (ontoportal-lirmm) no longer resolves.

What to take from this band is interpretation, not measurement: it is derived from the survey's findings against one specific decision — upgrading a Zotero → DuckDB → MCP claim base for agronomy and soil-microbiome literature. Read it as an argument, and the cards as the evidence.

“Not documented” means the project's own repository and documentation do not establish it — not that it is absent. Self-reported benchmark numbers are named as self-reported and are not repeated as fact here. Abandoned repositories were kept deliberately: their abandonment is evidence about the field.
